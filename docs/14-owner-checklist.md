# Owner decision checklist
No owner decision is needed merely to use this package for bounded local work. The following decisions are pending for expanded scope.

## Before live YouCam
- [ ] Confirm exact event eligibility/team representative and account readiness.
- [ ] Select supported API/version/category; resolve image-spec discrepancy and verify price.
- [ ] Approve allowed image set, processing rights and public-demo rights separately.
- [ ] Review provider retention, deletion and camera-module terms; approve truthful consent copy.
- [ ] Specify who supplies/manages credentials; explicitly authorize any secret action.
- [ ] Approve exact endpoint, call/unit/currency caps including retries, allowed hosts and expiry.
- [ ] Accept offline evidence and identify the approved build/commit.

## Before deployment
- [ ] Approve provider, region, visibility, judge access and allowed data.
- [ ] Approve costs, resource lifetime, teardown owner/date and backup/retention behavior.
- [ ] Choose repository visibility and project license; review archive's conversation export before public sharing.
- [ ] Approve any real merchant integration separately; otherwise retain simulation.

## Before submission
- [ ] Recheck current official rules and schedule discrepancy.
- [ ] Confirm source/assets/third-party rights and any pre-existing work disclosure.
- [ ] Review exact description, screenshots, 1–3 minute video and build version.
- [ ] Confirm all simulation/recording labels and no unsupported impact claims.
- [ ] Approve exact publication destinations and final submission action.
- [ ] Confirm required availability through judging and eventual teardown.

## Approval record
Use the [template](../contracts/authorization-template.json) only after a real owner decision. Record owner identity, timestamp, action, approved artifact hash, permitted data, endpoint/destination, limits, expiry and reference to the approval. Never store credentials in it.

“Continue,” “looks good,” an available API key, a passed test or approval of the concept alone does not grant an unspecified external action. Ask a focused scope question only when the required authorization is actually missing.
