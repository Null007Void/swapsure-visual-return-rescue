# Demo and judge journey
Target a 2 minute 30 second recorded journey after implementation. The current package includes no generated previews or video.

| Time | Screen and action | Evidence |
|---|---|---|
| 0:00–0:15 | Introduce a shopper already initiating a return | Post-purchase problem and visible refund |
| 0:15–0:35 | Select “Too small” | Refuse VTO; explain fit limitation; normal size-exchange/refund route |
| 0:35–0:55 | New session: color dissatisfaction | Eligible invitation; shopper opts in; consent shown |
| 0:55–1:15 | Filter catalog and display up to three candidates | Stock, category, size selection and price reasons |
| 1:15–1:40 | Show visual alternatives | Mode label, preview disclaimer, shopper chooses |
| 1:40–2:00 | Revalidate and confirm $89 → $84 quote | Explicit human approval, $5 partial refund |
| 2:00–2:15 | Rescue Receipt and merchant ledger | $84 simulated retained original GMV, approval and stock evidence |
| 2:15–2:30 | Provider failure and image deletion | Refund remains usable; honest deletion scope |

Offline narration must say “simulated exchange” and “mock preview.” A later approved live recording must distinguish real YouCam rendering from simulated merchant transactions. Do not imply a fallback recording is a fresh live call.

Provide a resettable seed, one-click scenario selection, expected outcomes and no secret exposure. Judge instructions should identify the actual build version, supported browser, mode, limitations and test credentials only through the approved access process.

Use the refusal first: it demonstrates why this is a decision system. End on voluntary choice, not an invented revenue claim. No customer image, music, logo or clip enters a published video without rights review and owner publication approval.
